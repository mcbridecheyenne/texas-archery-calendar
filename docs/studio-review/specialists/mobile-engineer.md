## Theme contrast (WCAG, checked with a script)
Text colors in the theme pass AA (4.5:1) in both modes:
- Light: muted on background 5.36, primary on card 4.59, white-ish text on orange buttons 4.55 (just passes), warning on card 4.74.
- Dark: muted on background 7.45, button text on orange 5.64, primary on card 5.17.

The one weak spot is the input placeholder, which uses 60% muted: about 2.6:1 (in the table above). Hard-coded colors appear only where they are meant to be fixed: the share picture, the black full-screen photo/flyer viewer, and the photo counter.
